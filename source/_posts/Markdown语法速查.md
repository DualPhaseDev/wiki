Markdown 是一种轻量级标记语言，用纯文本格式编写文档，广泛应用于博客、文档、笔记等场景。

<!-- more -->

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文字样式

```markdown
**粗体**
*斜体*
~~删除线~~
`行内代码`
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](image.png)
```

## 列表

```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

## 代码块

````markdown
```python
print("Hello World")
```
````

## 引用

```markdown
> 这是一段引用文字
```

## 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
```

---

掌握这些基础语法，就能写出漂亮的 Markdown 文档了 🎉
