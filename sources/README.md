# 第 1 层 · 原始资料层（只读）

本目录是知识库的"事实来源"，**只读，一个字不改**。

## 两种存档形态

- **全文存档**：用户主动投喂的资料（链接/文字/PDF），原样全文保存。
  命名：`YYYY-MM-DD-资料标题.md`，文件头部记录元数据（标题、来源链接、收录日期、资料类型、备注）。
- **摘录卡**：研究入库（AI 检索收集）专用，不存全文，只存被词条实际引用的原文片段（逐字摘录）
  + 元数据（来源标题、原链接、收录日期、片段位置、资料类型标注"AI 检索收集"）。
  命名：`YYYY-MM-DD-主题-序号.md`。同一来源去重复用。

## 铁律

- 禁止修改、覆盖已有文件；同名冲突追加序号。
- 词条层的一切论断必须能追溯到本层的存档或卡片。
